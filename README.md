# PTE SGD 템플릿 퀴즈

PTE Academic Summarize Group Discussion 3가지 템플릿을 랜덤 빈칸으로 반복 학습하는 단일 파일 웹앱.

## 기능
- 3가지 템플릿 버전: 축소형 / 상세 수식형 / 의견 대립형
- 2가지 모드: 타이핑 입력 / 드롭다운 4지선다
- 4단계 난이도: 입문(3개) / 중급(5개) / 고급(8개) / 전체 빈칸
- 랜덤 빈칸: 새 문제마다 다른 조합
- 오답노트: 틀린 표현 목록 → 해당 버전 재도전
- 통계: 버전별 누적 정답률 바 차트 (localStorage 영구 저장)
- 다크모드 자동 지원 / 모바일 반응형

## 실행
index.html 파일을 브라우저로 열면 바로 실행됩니다.
