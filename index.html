버전 선택

파란색 = 외워야 할 구문  |  주황색 = 변수 자리

🎯 오디오 재생 전 — 뼈대(Frame) 잡기

오디오 시작 전 10초 준비 시간 동안 아래 틀을 종이에 미리 적어두세요.

T : (주제) S1 : (화자 1) S2 : (화자 2) S3 : (화자 3) CL : (결론/합의)
⚡ 오디오 초반 — 주제(Topic) 즉시 기록

오디오 시작 직후 나오는 토론 주제를 가장 먼저 적으세요.
→ 서론 "The discussion was about (주제)" 완성의 핵심입니다.

👥 오디오 진행 중 — 화자 구분 & 핵심 파악

반드시 S1 / S2 / S3 로 구분해서 기록 (섞으면 답변 구성 시 혼란)
화자 태도도 짧게 메모:

동의 → agree / 반대 → disag / 걱정 → worry / 낙관 → opti
✂️ 시간 단축 — 약어 & 기호 활용

단어를 다 적을 시간이 없으니 아래처럼 줄여서 쓰세요.

자음 중심 축약:

study → std lecture → lectr different → dffrnt important → imp

기호 활용:

→ : 결과 (예: worked → result) ★ : 중요 포인트 B! : 반대(But) 2 : to 4 : for X : not / 없음
📝 오디오 후반 — 결론(CL) 정리

마지막 부분에서 합의 사항 또는 다음 행동(Next Action)을 반드시 적으세요.
"끝났다"가 아니라 "누가 무엇을 하기로 했다"는 구체적 결론이 중요합니다.

💡 키워드가 너무 적으면?
적어둔 키워드 사이에 쉬운 주어 + 동사를 넣어 완전한 문장으로 만드세요.
PTE는 단어 나열이 아닌 완전한 문장을 채점 기준으로 삼습니다.
